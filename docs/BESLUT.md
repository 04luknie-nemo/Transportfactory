# Designbeslut

En post per beslut. Nyaste överst.

## Mall

### Datum: Rubrik

**Problem:** Vad skaver i koden? Vilket code smell syns?

**Signal:** Vad i problemet pekar mot lösningen?

**Beslut:** Mönster, eller att inget mönster behövs.

**Bortvalt alternativ:** Vad valde jag bort, och varför?

**Overkill eller fel när:** När vore mitt val fel?

**SOLID:** Vilken princip berörs?
